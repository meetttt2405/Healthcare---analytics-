# CIPAT - Healthcare Analytics

## Project Overview

This project is developed as part of the CIPAT (Continuous Internal Practical Assessment Task). The project focuses on **Healthcare Analytics** using Python and Data Science techniques.

The main objective of this project is to analyze healthcare data, perform data preprocessing, statistical analysis, visualization, and build a simple prediction model.

## Objectives

* Load and analyze healthcare datasets.
* Perform data cleaning and preprocessing.
* Use Python data structures and programming concepts.
* Perform statistical analysis.
* Analyze and visualize healthcare data.
* Apply machine learning techniques.
* Predict healthcare-related costs based on patient details.

## Main Features

### 1. Data Loading

The healthcare dataset is loaded using Python and Pandas.

### 2. Data Preprocessing

The dataset is cleaned by handling missing values, duplicate records, and other data issues.

### 3. Data Analysis

Statistical methods are used to understand the healthcare dataset.

### 4. Data Visualization

Different graphs and charts are created using Matplotlib and Seaborn.

### 5. Prediction

A simple machine learning model is used to predict healthcare costs based on patient information.
